## Introduction
Jawniche Palette is an extension for working with colors in After Effects.


## Features
* Host a collection of different color palettes, either pre-generated or upon user addition.
* Add a new palette.
* Add a new color to an existing palette.
* Remove an entire palette.
* Remove a color from an existing palette.
* Apply Fill colors to:
  * Shapes (change the FIll color. If no fill color exists, add a Fill with the selected color.)
  * Image (add a Fill effect with the selected color. If a fill color exists, replace the existing color with the selected color.)
  * Footage (add a Fill effect with the selected color. If a fill color exists, replace the existing color with the selected color.)
* When updating a color in any given palette, the layers that have that color applied by the extension gets updated to the new color.
